# MOON STP - Students & Employees Edition

Includes an animated GitHub Pages-ready web presentation and a PowerPoint backup.

Segmentation includes College Students, Young Employees, Freelancers/Remote Workers, Social Hangout Customers, Trend/Experience Seekers and Coffee Enthusiasts. The required ONE primary target remains College Students aged 18-24; Young Employees are an important secondary segment.

## Run
Open `index.html` in Chrome/Edge. Right arrow or Space = next; Left arrow = previous; F = fullscreen; SOUND = optional ambient effect.

## GitHub Pages
Upload the CONTENTS of this folder to a GitHub repository. Go to Settings > Pages > Deploy from a branch > main > /(root). The generated Pages URL will run the presentation anywhere.
